# The interface

> Part of [the documentation](/docs/README.md) → [Architecture: the interface](/docs/architecture/frontend.md).

The interface is the web application people actually open — the only piece of XANA that talks to the hub, and the only piece anyone interacts with directly. Everything described in [the guides](/docs/guides/README.md) happens here: signing in, setting up connectors and projects, and the day-to-day workbench flow.
